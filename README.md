# Smart Appointment and Resource Allocation System

## Project Overview
The Smart Appointment and Resource Allocation System is a web-based platform designed to manage appointment scheduling and service provider availability in a structured and conflict-free manner.

## Problem It Solves
Manual or semi-digital appointment systems often lead to double bookings, inefficient use of time slots, lack of visibility into availability, and poor coordination between users and service providers.

## Target Users (Personas)
- Service seekers who want to book and manage appointments
- Service providers who manage availability and view schedules
- Administrators who oversee system operations

## Vision Statement
To provide a scalable, user-friendly appointment management system that improves efficiency, transparency, and coordination using modern Agile and DevOps practices.

## Key Features / Goals
- Availability-based appointment booking
- Conflict-free scheduling
- Appointment lifecycle management
- Role-based access
- Scalable architecture

## Success Metrics
- App runs successfully using Docker
- App accessible via browser
- Clear separation of frontend and backend
- All Review-1 deliverables completed

## Assumptions & Constraints
- Web-based access only
- Free/open-source tools
- Limited academic timeline
